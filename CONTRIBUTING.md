# Contributing

Contributions should help an intern practice a focused SWE or QA skill.

## Add an algorithm exercise

1. Choose the appropriate difficulty folder.
2. Add a `.js` implementation and a matching `.test.js` file.
3. Document the task, assumptions, and expected complexity in the implementation.
4. Add tests for typical input, boundaries, and at least one tricky case.
5. Include a short problem description and example in that level's README.
6. Run `npm test` and make sure all tests pass.

Prefer clear names and small functions. Tests should verify observable behavior, not implementation details. Do not copy a full problem statement from a copyrighted source; describe the learning goal in your own words.

## Add a QA exercise

Describe the system under test, the learner's task, and what a good submission should contain. Include relevant edge cases and risks without prescribing a single implementation.
